# Print Picker

选取网页里的任意元素，只把选中的那块交给浏览器打印（Ctrl/⌘+P → 目标选「另存为 PDF」即可导出 PDF）。

## 安装

1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`），开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本目录 `print-picker`。
3. 想在内网/本地 `file://` 页面上用，需在扩展详情里打开「允许访问文件网址」。

## 用法

1. 打开目标页面，点工具栏的 Print Picker 图标，进入选取模式（页面变十字光标）。
2. 移动鼠标，蓝色框就是待打印区域；蓝色标签显示 `Print Picker · 元素名 · 宽 × 高`。
3. 按 **↑**（或 **Tab**）上选父级（可连续按，直到 `body`），按 **↓**（或 **Shift+Tab**）逐层退回。
4. 按住 **Ctrl**（macOS 用 ⌘）点击可多选：每块被选中的区域显示实线框和序号角标，再次 Ctrl 点击同一块即移出。
5. 按住 Ctrl 期间仍是选取态（十字光标、可继续 Ctrl 点击增删）；**松开 Ctrl** 后才进入打印态：光标变成打印机光标，虚线框与元素标签消失，点页面任意位置（或按 Enter）即打印已选的那几块。
6. 再按住 Ctrl 可回到选取态继续增删；多选状态下 ↑ / ↓（或 Tab / Shift+Tab）调整为**刚刚选中**的那一块（换父级或退回子级），其他已选块不动；目标已经是别的选中块时不动，避免重复选中。
7. 每个选中块的**右上角有三个小按钮 ↑ / ↓ / ×**：↑↓ 单独调整那一块的范围（换父级 / 退回子级），× 把它移出多选；都不影响其他选中块，也不会误触打印。↑↓ 到顶或到底时置灰。
8. 把选中项删光、按 Esc 或退出后光标恢复十字；十字态下 ↑ / ↓ 仍作用于当前悬停的元素。
9. 没有选中项时，回车或左键点击直接打印当前虚线框框住的那一块。
10. **Esc** 取消（连多选一起清空，光标复原）；选取状态下再点一次工具栏图标也是取消。

### 用选择器直接定位

按 **`/`** 弹出输入框，输入 CSS 选择器（如 `main .card`、`#price`、`div[data-id]`）：

- 输入时实时显示「找到 N 个」，并给第一个命中元素画虚线框
- 选择器写错会红框提示，找不到元素提示「没有匹配到元素」
- **Enter** 确认：只命中 1 个就设为当前目标（之后仍可 ↑ / Tab 调层级）；命中多个则整批加入多选
- **Esc** 取消输入；点页面其他位置也会关掉输入框，且不会触发打印

## 选项

在 `chrome://extensions` 里点本扩展的「详情 → 扩展选项」（或右键工具栏图标选「选项」）打开设置页：

- **一级子节点分页**（默认关闭）：开启后，选中元素的一级子节点若是并列的 `div`，打印时从第二个起各自另起一页；关掉则整块内容连续排布。改动即时生效，无需重载扩展或刷新页面。

## 结构

```
manifest.json
icons/                   16/32/48/128 扩展图标；print32.png 用作打印态光标
options/                 选项页（一级 div 分页开关）
LICENSE                  PolyForm Noncommercial 1.0.0
src/background.js        点击图标 → 向当前标签页注入选取脚本
src/content/picker.js    选取浮层 + 多选/打印态 + 打印隔离逻辑（单文件，无外部依赖）
```

## 实现要点

- 浮层放在 Shadow DOM 里，且 `pointer-events: none`，不影响 `elementFromPoint` 命中页面的真实元素，也不会被站点样式污染。
- 打印隔离：把「所有选中元素及其祖先链」取并集作为保留集合（`data-pp-chain`），集合外的兄弟节点逐级隐藏（`data-pp-hide` + `@media print { display:none !important }`），保留链还原 `position: static / overflow: visible / height: auto`，避免被固定定位或滚动容器裁成半页。单选与多选走同一套逻辑。
- 加了 `print-color-adjust: exact`，背景色、底纹按原样打印。
- 打印时清空 `html` / `body` 的底色（连带背景图、渐变），避免整页灰底被一起打印；只去掉选中元素自身的 `box-shadow`，内部卡片阴影保留。
- 选中元素的一级子节点若是并列的若干 `div`，从第二个起自动加分页（`break-before: page`），首个留在第一页；父容器是 flex/grid（会忽略分页规则）或子节点是行内级时，打印时临时转成块级让分页生效。该行为默认关闭，可在选项页打开（`chrome.storage.sync` 存 `divPageBreak`，打印时实时读取）。
- 打印结束后（`afterprint` / 窗口重新获得焦点）移除临时样式并恢复滚动位置。

## 已知限制

- 只处理主框架，iframe 内的元素不在选取范围。
- 选中元素依赖父级布局时（如 flex 定宽卡片），打印宽度可能和屏幕不完全一致，可用 ↑ 多选一层。
- 元素内部若由 JS 分页/懒加载渲染，打印时不会补充未加载的部分。
